# 01. 요구사항 명세

## 배경

AWS SAA-C03 자격증 준비 자료 PDF 5개를 갖고 있으나, PDF 형태로는 학습이 비효율적이다.

- 1019문항을 PDF로 풀면 진도 추적이 불가능하고, 틀린 문제를 다시 찾아가기 어렵다
- 암기 노트와 문제가 분리돼 있어 문제를 풀다 막혔을 때 참조가 끊긴다
- PC와 폰을 오가며 공부하는데 진도가 이어지지 않는다

## 목표

문제 풀이를 중심에 두고, 진도가 기기 간에 이어지는 학습용 웹 애플리케이션을 만든다.

**부차 목표**: NestJS 학습. 이 프로젝트는 NestJS를 실제로 써보는 연습장을 겸한다. 따라서 백엔드가 형식적 껍데기가 아니라 인증·도메인 로직·집계를 실제로 담당해야 한다.

## 사용자

**개인 1명(레포 소유자)**. 다중 사용자 시나리오는 범위 밖이다.

이 전제가 다음 결정들의 근거가 된다.

- 기기 간 동기화 충돌을 last-write-wins로 단순 처리한다
- Postgres RLS를 v1에서 켜지 않는다 (→ `05-database.md`)
- 데이터 규모가 작다고 가정하고 사전 집계 테이블을 두지 않는다

다중 사용자로 확장할 경우 위 세 가지를 전부 재검토해야 한다.

## 비기능 요구사항

**성능**
- 폰 첫 진입에서 문제 목록·필터가 즉시 동작해야 한다 → 전체 문제 데이터(2.7MB)를 받지 않고 인덱스(약 60KB)만으로 처리
- 문제 본문은 100문항 단위 청크로 필요할 때만 받는다

**가용성**
- 개인 학습용이므로 SLA 요구 없음
- 정적 데이터(문제·노트·해부서)는 CDN에서 서빙하므로 백엔드가 죽어도 문제 풀이 자체는 가능해야 한다 (진도 저장만 실패)

**저작권 / 보안**
- 원본 PDF와 추출 데이터는 제3자 저작물이다 (노트 하단 `© 2026 contatto. All rights reserved.`)
- 레포가 **public**이므로 어떤 추출 데이터도 git에 커밋하지 않는다
- 데이터는 소유자의 CDN에만 존재한다. CDN은 인증이 없어 URL을 알면 누구나 받을 수 있다 — 경로 비밀(랜덤 프리픽스)과 CORS가 방어선이므로, 실제 경로를 레포·문서·이슈에 적지 않는다

**데이터 보존**
- 해부서 판독 결과는 스크립트로 재현할 수 없는 유일한 산출물이다 (이미지 61장 수동 판독)
- 덮어쓰기 사고를 구조적으로 막기 위해 버전 경로(`v1`, `v2`)를 쓰고 기존 버전을 삭제하지 않는다
- S3 버킷 버저닝을 활성화한다

## 제약

- 배포는 Vercel
- DB는 Supabase (Postgres)
- CDN은 기존 보유 자산 `static-cdn.scent-jo.dev` (S3 ap-northeast-2 + CloudFront)
- 프론트는 Next.js, 백엔드는 NestJS, pnpm workspaces 모노레포

## 성공 기준

1. 폰에서 열어 로그인하면 PC에서 풀던 지점부터 이어서 풀린다
2. 1019문항 전체가 손실·중복 없이 파싱되고 자동 검증을 통과한다
3. 틀린 문제만 모아 다시 풀 수 있다
4. 65문항 모의고사를 중간에 닫았다가 다른 기기에서 이어서 완료할 수 있다
5. 카테고리별 정답률로 약한 영역을 식별할 수 있다

# 데이터 변경 이력

추출 데이터는 git에 없다 (저작권, `03-architecture.md`). 그래서 **"어떤 버전에 무엇이 들었고, 왜 바꿨는지"를 기록할 곳이 여기뿐이다.**

변경 사유만 적으므로 저작권 문제가 없다. 데이터 자체는 절대 여기 옮겨 적지 않는다.

## 규칙

- 새 버전을 배포할 때마다 항목을 추가한다
- 최신이 위로 온다
- **문항 내용을 인용하지 않는다.** 문항 번호와 변경 성격만 적는다
- 배포 후 `MEMORY.md`의 CDN 배포 버전을 갱신한다

## 형식

```
## v2 · 2026-09-XX

**사유** 한 줄 요약

- Q.412 선택지 D 파싱 누락 수정 (원본 줄바꿈 처리)
- 별칭 사전에 항목 추가 → 데이터베이스 카테고리 태깅 8건 정정
- 해부서 PART 2 · 2-11 절 오타 3건

**영향** 태깅이 바뀐 문항의 기존 시도 기록은 그대로 유지된다.
카테고리별 통계는 다음 조회부터 새 태깅으로 계산된다.
```

## 이력

_아직 배포된 버전이 없다._

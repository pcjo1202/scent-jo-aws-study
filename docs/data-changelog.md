# 데이터 변경 이력

추출 데이터는 git에 없다 (저작권, `03-architecture.md`). 그래서 **"어떤 버전에 무엇이 들었고, 왜 바꿨는지"를 기록할 곳이 여기뿐이다.**

변경 사유만 적으므로 저작권 문제가 없다. 데이터 자체는 절대 여기 옮겨 적지 않는다.

## 규칙

- 새 버전을 배포할 때마다 항목을 추가한다
- 최신이 위로 온다
- **문항 내용을 인용하지 않는다.** 문항 번호와 변경 성격만 적는다
- 배포 후 `MEMORY.md`의 CDN 배포 버전을 갱신한다

## 형식

```
## v2 · 2026-09-XX

**사유** 한 줄 요약

- Q.412 선택지 D 파싱 누락 수정 (원본 줄바꿈 처리)
- 별칭 사전에 항목 추가 → 데이터베이스 카테고리 태깅 8건 정정
- 해부서 PART 2 · 2-11 절 오타 3건

**영향** 태깅이 바뀐 문항의 기존 시도 기록은 그대로 유지된다.
카테고리별 통계는 다음 조회부터 새 태깅으로 계산된다.
```

## 이력

## v1 · 2026-09-04

**사유** 최초 배포. SJO-4~SJO-7의 추출·검증 산출물을 CDN에 올린다.

- 문항 1019개를 100문항 단위 청크 11개로 분할 (`questions/chunk-001..011.json`)
- 채점·필터용 인덱스 1019행 (`questions/index.json` — `answer`·`choiceCount`·태그 포함)
- 한줄노트 203개 · 비교노트 48쌍 (`notes/`)
- 파서 골든 픽스처 6문항의 원문·파싱 결과 12파일 (`fixtures/questions/`) — `data:pull`이 데이터와 함께 복원한다
- **해부서는 제외한다.** 자산화(E2)가 미완이라 optional 자산 규칙대로 뺐다 (`04-data-model.md`). `/anatomy` 화면은 anatomy가 포함된 다음 버전부터 동작한다

**영향** 첫 배포라 갱신되는 기록이 없다. `data:verify` 55항목 위반 0건으로 게이트를 통과했고, CDN에서만 복원한 트리가 같은 게이트와 골든 테스트 244개를 다시 통과했다.

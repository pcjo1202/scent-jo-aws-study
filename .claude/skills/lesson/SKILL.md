# /lesson — 실수 기록

무엇이 잘못됐고 왜였는지를 LESSONS.md에 남긴다. 목적은 재발 방지다.

1. **기록** — LESSONS.md 맨 아래에 추가:

   ```
   ## YYYY-MM-DD <한 줄 제목>
   - 증상: 무엇이 잘못됐나
   - 원인: 왜 그랬나 — 잘못된 가정·헷갈린 지점을 구체적으로
   - 교정: 올바른 방법
   - 관련: SJO-N / 파일 / docs 절
   ```

2. **재발 확인** — LESSONS.md에 같은 원인이 이미 있으면(2회째) 승격을 제안한다:
   - 판단 규칙이면 → CLAUDE.md "어기기 쉬운 규칙"에 한 줄
   - 기계적으로 막을 수 있으면 → hookify로 훅 생성
   - 승격했으면 원 항목에 `→ 승격됨 (CLAUDE.md | 훅)` 표시 (append-only의 유일한 예외)

3. **커밋** — 기록만 있는 커밋도 허용: `docs: lesson — <제목>`

## gotchas

- "나중에 기록해야지"는 기록 안 한다는 뜻이다 — 발견 즉시 기록
- 증상만 적고 원인을 안 적으면 재발 방지가 안 된다 — 원인이 핵심
- 사용자가 지적해준 실수가 최우선 기록 대상이다

# /start — 이슈 착수

인자: 이슈 ID (예: `SJO-2`). 없으면 로드맵 순서상 다음 이슈를 제안한다.

1. **동시 진행 확인** — In Progress인 이슈가 이미 2개면 착수하지 않는다. 하나를 먼저 `/done`으로 닫거나 사용자에게 묻는다.
2. **차단 확인** — 이슈의 blocked-by가 모두 Done인지 확인한다. 아니면 중단하고 보고.
3. **할당** — 이슈를 `In Progress` + `me`로 갱신한다.
4. **읽기** — 이슈의 목표·완료 정의·체크리스트와, 이슈가 참조하는 docs/ 절을 읽는다.
5. **모호성 해소** — 구현이 갈릴 명세 공백이 있으면 코딩 전에 해소한다 (SJO-30 확인, 결정은 해당 doc에 반영 후 체크).
6. **계획** — 체크리스트를 실행 순서로 정렬한다. 3단계 이상이면 계획을 사용자에게 한 번 보이고 시작한다.

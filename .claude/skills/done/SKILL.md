# /done — 이슈 종료

인자: 이슈 ID (예: `SJO-2`). 없으면 In Progress인 이슈 중에서 확인한다.

1. **DoD 검증** — 이슈의 완료 정의를 실제로 실행·확인한다. 명령이면 돌리고 출력을 본다. 통과 못 하면 여기서 중단.
2. **코드 리뷰** — 이슈의 전체 diff(착수 시점 커밋 기준)로 `pr-review-toolkit:code-reviewer` 서브에이전트를 실행한다.
3. **디자인 리뷰** — diff에 `apps/web`의 컴포넌트·스타일 변경이 포함되면 `design-reviewer` 서브에이전트도 실행한다.
4. **지적 반영** — P1은 수정 필수. P2는 수정하거나 보류 사유를 이슈 코멘트로 남긴다. 수정했으면 커밋.
5. **Linear 갱신** — 체크박스를 patch로 `[x]` → 검증 결과·리뷰 요약을 코멘트 한 줄 → state `Done`.
6. **MEMORY.md** — 외부 상태(CDN·인프라·마이그레이션) 변경이 있었으면 갱신하고 함께 커밋한다.

리뷰는 이슈당 1회. 커밋마다 돌리지 않는다.
